# AGENTS.md -- руководство для AI-агентов

## О проекте

* Проект -- электронное учебное пособие на тему **«Введение в командную строку Linux»**.
* Материалы оформлены с использованием **JupyterBook** версии 1.
* Проект публикуется в виде статического HTML-сайта на `GitHub Pages` по адресу `https://wolodyx.github.io/unixshell`.
* Для прохождения пособия доступна виртуальная машина с ОС Ubuntu.
  Инструкции по ее созданию и настройке описаны в `./src/setup.md`.


## Структура проекта

* `src/*.md` -- разделы;
* `src/images/*.png` -- изображения, используемые в разделах;
* `src/images/*.excalidraw.png` -- изображения, оформляемые с помощью расширения `excalidraw`;
* `_build` -- результат сборки учебника.


## Сборка в HTML-страницы

Сборка и развертывание учебника на стороне GitHub осуществляется через `GitHub Actions`.

Сборка учебника на локальном компьютере происходит в Docker-контейнере расширением DevContainer в среде VSCode.
Результаты сборки сохраняются в каталоге `_build`.


## Соглашение для контента

* `sppo` -- имя пользователя в машине;
* `pc` -- название машины;
* для длинных тире использовать `--`;
* для кавычек в тексте использовать только символы `"` и `'`;
